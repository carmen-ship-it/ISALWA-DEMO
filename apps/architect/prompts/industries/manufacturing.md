# Manufacturing Discovery Lens

Focus on how demand becomes finished goods.

## Listen for

- Quote → order → work order → production → QC → ship
- BOM ownership and revision chaos
- Shop-floor communication (paper, WhatsApp, tribal knowledge)
- Inventory accuracy vs. system truth
- Machine downtime and scheduling friction
- Quality escapes and rework loops

## Prefer questions about

- How sales hand work to production
- How production knows what to make next
- Where specifications live
- What happens when a rush order arrives
- How scrap, rework, and shortages are handled

## Do not

- Start with MES/ERP product talk
- Assume every manufacturer is discrete manufacturing
