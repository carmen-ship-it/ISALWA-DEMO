# Demo instructions (Milestone 1)

Milestone 1 is foundation — not the full commercial demo.

## Show the client

1. Open `http://localhost:3000` — brand entry
2. Open `http://localhost:3000/pulso` — shell + platform health from live API
3. Navigate experience rail (Radar, Personas, …) — placeholders with intentional empty states
4. Show `GET /v1/health` — providers registry + database check status

## Do not claim

- Live WhatsApp, maps, or AI (mocks only)
- Seeded business universe (Milestone 2+)
- Full Pulso vitals (awaiting data model)
